# PEEK course experiments

These files record the course experiments with [PEEK](https://github.com/xiexbing/peek). The upstream reference is `3aca72b63c1dd6433193c0857b965acecdbfbb8a`. The integration evidence was collected from the experiment checkout at `6fbf2205f1c8bc6fe55746d75860e23779b003a2`.

- [Integration](integration/B3_integration_handoff.md) contains the SGLang setup, validation scripts and tests. The scripts use the original experiment paths and expect a separate PEEK checkout.
- [Benchmark](benchmark/B4_REPORT.md) contains the B4 report, selected result tables and the original runner and analysis scripts. References to raw runs and runtime dependencies describe inputs from the original environment.
- [Admission audit](admission-audit/V23_DECISION.md) contains the V23 decision, source map, trace analysis, machine-readable results and audit script.
- [Agent session cache exploration](../exploration/Agent-Session-Cache-Exploration.md) contains the standalone Python simulation and its results.

The upstream license and notice are included in this directory.
